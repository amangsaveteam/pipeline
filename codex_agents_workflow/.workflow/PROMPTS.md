# 日常提示词

```text
完成 <目标>。先看相关实现和项目约束，直接修改代码，复用并补充必要回归测试，同步受影响的现有文档，运行相关检查。
默认由主 agent 完成，不初始化 workflow、不生成任务契约或阶段报告。仅在具体风险需要独立验证时调用一个合适的审查/测试角色。
保留已有用户修改；范围纠正留在当前任务，不新建 V2/V3。最终简短说明修改、验证和未完成项。
```

## 按需审查

```text
只读审查 <指定差异>，重点核查 <风险>。使用已有检查结果，仅在具体疑点需要时补充验证。
直接返回有依据的问题与结论，不生成报告文件，不启动完整工作流。
```

完整状态机仅在明确选择后按 [工具手册](README.md) 使用，不是上述提示词的前置条件。
